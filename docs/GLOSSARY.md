The spelling `Raveil` retains an association with Ravel and evokes French
`réveil` (“awakening”). Code, package, and namespace identifiers use
`raveil`.

Use a component's formal name in headings, tables, diagrams, and the first use
in each document or independent section. Use its short name thereafter in the
same section. Code, package, directory, CLI, and stable-record identifiers are
not renamed by this documentation convention.
