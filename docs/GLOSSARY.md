# Glossary

Last updated: 2026-08-08

| Term | Meaning |
|---|---|
| Raveil | the complete adaptive computing research project |
| Sonatine | RISC-V microkernel and trusted execution authority |
| Daphnis | adaptive graph/dataflow implementation plane |
| Miroirs | graph IR, transformations, and structural verifier |
| Pavane | deterministic semantic reference executor/oracle |
| Ondine | object memory, residency, spill, stream, rematerialization |
| La Valse | proposal generation, search, placement, and mapping |
| Boléro | persistent runtime, retrieval, and variant selection |
| Scarbo | adversarial tests, fuzzing, and fault injection |
| ProgramIdentity | stable identity of immutable program semantics |
| ExecutionContract | accepted effects, resources, numerical rules, and authority bounds |
| GraphVariant | sealed executable graph plus lineage and target identity |
| MemoryPlan | object residency, spill, stream, and recomputation decisions |
| Experience | measured successes, failures, lineage, uncertainty, and policy evidence |
| Adaptive Council | staged collection of cheap and expensive proposers/reviewers |
| HCR | Headroom Capture Rate against a trusted baseline and offline oracle |
| NTR | Negative Transfer Rate |
| dynamic island | bounded execution region for irregular or data-dependent work |
| evidence class | analytical, simulated, emulated, FPGA, or silicon result category |

The spelling `Raveil` retains an association with Ravel and evokes French
`réveil` (“awakening”). Code, package, and namespace identifiers use
`raveil`.
