# Raveil v0.0000000000006 — Native shell completion

Status: Published GitHub Pre-release

This candidate adds bounded Tab completion to the Native Interactive CLI while
preserving the Native Command Graph, tensor Graph MVP, Sonatine, Linux harness,
owned contracts, Experience, and all prior experiment and failure evidence.

## What changed

- Tab completes documented top-level commands and graph subcommands/options;
- Command Graph positions complete only the fixed allowlisted tool names;
- file positions complete bounded virtual-workspace paths, including hidden
  names and directory suffixes, while omitting symlinks and host paths; and
- GNU readline and macOS libedit use native line editing and ephemeral history.

Completion grants no authority. Every resulting command is reparsed and passes
the existing workspace, structural, semantic, baseline-first, commit/rollback,
and exclusive-output checks.

## Run the demo

```bash
git clone https://github.com/bhind/raveil.git
cd raveil
git checkout v0.0000000000006
mkdir -p /tmp/raveil-command-demo
python3 -m raveil shell --workspace /tmp/raveil-command-demo
```

At `raveil>`, try `he<Tab>`, `graph <Tab>`, or `cat /<Tab>`, then run the
Command Graph walkthrough in `docs/guides/NATIVE_COMMAND_GRAPH.md`.

## Evidence and limitations

The candidate is verified by local macOS CI, a real libedit PTY interaction,
GNU/Linux arm64 focused tests, and retained QEMU emulation regressions. These
are host correctness, portability, and emulation-correctness facts only.

There is no persistent history, fuzzy matching, shell expansion, arbitrary PATH
completion, or external completion script. T-0099 remains application-level
workspace containment rather than an OS security boundary; T-0100 remains
open. EXP-0004 remains Planned. This release makes no performance, scheduling,
energy, FPGA, ASIC, silicon, or Sonatine performance claim. No assets or hosted
CI/CD workflows are included.
