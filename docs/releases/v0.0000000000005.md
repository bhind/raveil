# Raveil v0.0000000000005 — Native Command Graph

Status: Prepared GitHub Pre-release candidate; not published

This candidate adds a bounded Command Graph vertical slice to the Native
workspace while preserving the tensor Graph MVP, Sonatine, Linux harness,
owned contracts, Experience, and all prior experiment and failure evidence.

## Command Graph demo

- a strict, deterministic `raveil.command-graph-program/v1` owns command nodes,
  dependencies, virtual paths, fixed tool identities, and resource policy;
- `run` provides the independent source-order correctness baseline;
- `graph compile`, `graph show`, and `graph execute --compare` compile and run
  the ready-set DAG, then publish declared outputs only after exact semantic
  agreement;
- `graph benchmark` records balanced development-smoke observations while
  excluding invalid pairs and making no performance claim; and
- arbitrary executables, shell expansion, `shell=True`, append, background
  work, ambient PATH lookup, network tools, and deletion remain unsupported.

## Run the demo

Requirements: Python 3, standard host file tools, and an existing workspace.

```bash
git clone https://github.com/bhind/raveil.git
cd raveil
git checkout v0.0000000000005
mkdir -p /tmp/raveil-command-demo
python3 -m raveil shell --workspace /tmp/raveil-command-demo
```

At `raveil>`, run:

```text
write /input.txt "INFO start\nERROR failed\nERROR retry\n"
run cat /input.txt | grep ERROR | wc -l
graph compile cat /input.txt | grep ERROR | wc -l
graph show
graph execute --compare
graph benchmark --warmups 3 --repetitions 20
graph result /command-result.json
cat /command-result.json
exit
```

boundary; T-0100 remains open. This candidate makes no latency, speedup,
