# Raveil v0.0000000000003 — Interactive control fix

Status: Pre-release candidate

This release corrects the first human-operated Sonatine demo. The immutable
v0.0000000000002 release could flood its UART with 100 Hz context-transition
diagnostics and silently discarded `Ctrl+C` as an unsupported control byte.

## Fixes

- routine timer preemption no longer writes `clint-preempt` prose;
- the bounded self-test still verifies that real preemption occurred;
- `Ctrl+C` at `raveil-u>` uses the same current-task-checked shutdown path as
  `exit`;
- real-QEMU CI now exercises ETX shutdown and rejects recurring transition
  spam; and
- the Makefile selects either `riscv64-unknown-elf-` or Homebrew's
  `riscv64-elf-` toolchain when installed.

## Run the interactive demo

Requirements: GNU Make, `qemu-system-riscv64`, and either supported
freestanding RV64 GCC toolchain.

```bash
git clone https://github.com/bhind/raveil.git
cd raveil
git checkout v0.0000000000003
make -C sonatine run
```

At `raveil-u>`, try `help`, `ls`, `cat`, `stat`, `write`, `jobs`, `run`,
`result`, `cancel`, and `exit`. Pressing `Ctrl+C` also exits QEMU.

For an existing clone:

```bash
git fetch --tags
git checkout v0.0000000000003
make -C sonatine clean run
```

## Replayable host demo

```bash
make -C sonatine
python3 -m raveil sonatine-demo \
  --sonatine-kernel sonatine/build/sonatine.elf \
  --output sonatine/build/raveil-sonatine-demo.json
python3 -m json.tool sonatine/build/raveil-sonatine-demo.json
```

## Evidence boundary

This is host correctness and QEMU emulation correctness only. It makes no
latency, energy, FPGA, ASIC, silicon, production-isolation, POSIX, or
general-purpose compiler claim. No hosted CI/CD or generated measurement
bundle is included.
