# Raveil v0.0000000000004 — Native CLI workspace

Status: Published GitHub Pre-release

This candidate grows the Native userspace CLI into a small human-operable
workspace while preserving the existing guarded graph path and every prior
Sonatine, Linux, contract, Experience, and experiment artifact.

## Native workspace

- `python3 -m raveil shell --workspace PATH` fixes one existing host directory
  as virtual `/` for the lifetime of the Session;
- `pwd`, `cd`, `ls`, `cat`, `stat`, `mkdir`, and bounded exclusive `write`
  provide the minimum file workflow;
- parent traversal, symlink components, broken links, special files, excessive
  paths/files/listings, root replacement, and overwrite fail closed; and
- `result PATH` writes the existing strict `raveil.graph-mvp-result/v1` only
  inside the selected workspace.

## Run the Native demo

Requirements: Python 3 and a C11 compiler available as `cc`.

```bash
git clone https://github.com/bhind/raveil.git
cd raveil
git checkout v0.0000000000004
mkdir -p /tmp/raveil-demo
python3 -m raveil shell --workspace /tmp/raveil-demo
```

At `raveil>`, run:

```text
pwd
mkdir output
graph create gemm --m 8 --n 8 --k 8
graph show
variants
propose
execute
result /output/result.json
ls /output
stat /output/result.json
cat /output/result.json
exit
```

For an existing clone after publication:

```bash
git fetch --tags
git checkout v0.0000000000004
mkdir -p /tmp/raveil-demo
python3 -m raveil shell --workspace /tmp/raveil-demo
```

## Evidence and limitations

The Native workflow reuses GraphCompiler, the analytical adviser,
Miroirs/Pavane validation, GraphExecutor, and NativeCBackend. The trusted
baseline runs first; advice may abstain; commit or rollback remains explicit.

T-0099 is application-level workspace containment and host-correctness evidence.
It is not an OS security boundary and does not isolate hostile native code or
eliminate every filesystem race. T-0100 remains open for descriptor-relative
resolution and platform-enforced worker isolation. This release makes no new
latency, energy, FPGA, ASIC, silicon, or Sonatine performance claim. No assets,
hosted CI/CD workflow, or generated measurement bundle are included.
