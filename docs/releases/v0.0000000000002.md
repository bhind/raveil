# Raveil v0.0000000000002 — Sonatine operator demo

Status: Pre-release candidate

This demo adds a bounded, line-oriented Sonatine U-mode shell and a strict
host runner. It is intentionally not a Unix/POSIX shell.

## Quick interactive demo

Requirements: GNU Make, `qemu-system-riscv64`, and a freestanding RV64 GCC
toolchain. The default toolchain prefix is `riscv64-elf-`; pass
`CROSS_COMPILE=riscv64-unknown-elf-` if that is how your tools are named.

```bash
git clone https://github.com/bhind/raveil.git
cd raveil
git checkout v0.0000000000002
make -C sonatine run
```

At the `raveil-u>` prompt, try:

```text
help
ls
cat
stat
write
cat
jobs
run
result
run
cancel
result
exit
```

`cat`, `echo`, and `write` use fixed demo values. Commands are bounded to eight
ASCII bytes. There is no path parser, process loader, pipe, networking, or
general Unix compatibility.

## Replayable host demo

Requires Python 3.11 or newer in addition to the tools above:

```bash
make -C sonatine
python3 -m raveil sonatine-demo \
  --sonatine-kernel sonatine/build/sonatine.elf \
  --output sonatine/build/raveil-sonatine-demo.json
python3 -m json.tool sonatine/build/raveil-sonatine-demo.json
```

The runner drives the fixed VFS plus completed/cancelled job transcript and
accepts only the versioned 18-frame protocol.
