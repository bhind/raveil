# Raveil v0.0000000000002 source demo

Status: release candidate
Target: the immutable `v0.0000000000002` tag must peel to the audited release commit

## What you can run

- an owned `GraphProgram` and `ExecutionContract` for bounded GEMM and
  GEMM+bias+ReLU;
- canonical baseline, loop-interchanged, tiled, and legal fused variants;
- advisory proposal or abstention;
- Miroirs Graph Compiler structural admission;
- Pavane Semantic Oracle independent integer checksum validation;
- baseline-first native execution with explicit commit or rollback;
- an 8x8x8 GEMM correctness path through Sonatine/QEMU;
- the interactive `raveil-u>` Sonatine U-mode command shell.

## Fastest path

Requires Python 3.11 or newer and a C11 compiler:

```bash
git clone https://github.com/bhind/raveil.git
cd raveil
git checkout v0.0000000000002
python3 -m raveil graph-mvp --backend native \
  --family gemm_bias_relu --m 128 --n 128 --k 128 \
  --inner-iterations 20 --warmups 3 \
  --output /tmp/raveil-native-demo.json
python3 -m json.tool /tmp/raveil-native-demo.json
```

Look at `proposal`, `observations`, `outcome`, `selected_variant`, and
`rollback_reason`. Both commit and rollback are valid outcomes; the candidate
must pass semantic validation and improve that local observation to commit.

## Sonatine/QEMU path

Requires GNU Make, a freestanding RV64 compiler, and
`qemu-system-riscv64`:

```bash
make -C sonatine CROSS_COMPILE=riscv64-elf-
python3 -m raveil graph-mvp --backend sonatine-qemu \
  --family gemm --m 8 --n 8 --k 8 \
  --sonatine-kernel sonatine/build/sonatine.elf \
  --output /tmp/raveil-sonatine-demo.json
```

Use `make -C sonatine run CROSS_COMPILE=riscv64-elf-` to interact with the
`raveil-u>` shell. Its commands are `help`, `info`, `ticks`, `ipc`, `fs`, and
`exit`.

timings are control inputs, not benchmark claims. QEMU reports no execution
latency. The release makes no speedup, energy, FPGA, ASIC, silicon, production
isolation, or general-purpose compiler claim. EXP-0003 remains a preserved
negative result for its preregistered 5% Experience-transfer hypothesis.
