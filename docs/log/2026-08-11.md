# 2026-08-11

## T-0084 Linux driver-development harness

- PM review retained ADR-0003: Linux does not replace the permanent
  RISC-V/Sonatine control and authority path. ADR-0019 makes Linux a
  non-authoritative development and transport-validation host.
- Added a fixed 32-byte request/completion v1 ABI with PING/NOP only and a
  pure-C one-inflight core. Invalid magic, version, size, flags, and opcode
  fail closed; busy and empty states remain distinct.
- Added Linux-only same-UID `SOCK_SEQPACKET` daemon/client sources. The daemon
  requires an absolute `XDG_RUNTIME_DIR`, creates a private endpoint under
  umask 0077, rejects partial messages with `MSG_TRUNC`, and exposes no network,
  root, kernel module, pointer, file-descriptor passing, DMA, MMIO, or
  Experience boundary.
- `scripts/ci-local.sh` exited 0 with all 54 tests, release/debug Sonatine
  builds, DWARF checks, and QEMU smoke on macOS 26.5.1 arm64 using Python
  3.14.6, Apple clang 21.0.0, `riscv64-elf-gcc` 16.1.0, binutils
  2.47.20260726, and QEMU 11.0.3.
- `docker build -f linux/Dockerfile -t raveil-linux-driver linux` exited 0 on
  Docker Linux arm64. Debian bookworm GCC 12.2.0 compiled both Linux-only
  binaries warning-free. The image identity was
  `sha256:1f19fe3b2be57fbb159ded26887afd2986341b05d4d25d91280bc861b3d46231`.
- The non-root smoke used UID/GID 65534 and a mode-0700 `/runtime` tmpfs. The
  Docker frontend left the invocation in Created state in this session, so the
  same configured container was started explicitly with `docker start -a`.
  It exited 0, observed socket mode 600, printed
  `raveil linux driver ping: OK`, and verified endpoint cleanup.
- Host-core and Linux-container results are correctness evidence only.
  Kernel-device, QEMU-device, FPGA, silicon, and performance evidence remain
  separate and are not claimed.

## T-0030 bounded JobDescriptor and CompletionRecord

- Accepted ADR-0020 and added a platform-neutral little-endian, pointer-free
  JobDescriptor/CompletionRecord v1 contract. The schema caps each job at four
  generation/version/range/effect object references and requires explicit
  runtime/input/output/scratch ceilings.
- Completion validation requires nonzero claimed execution epoch, sequence,
  and cookie; T-0031 still owns issuance and replay state. Executed outputs
  must be the job's WRITE objects with advanced versions;
  rejected/cancelled/fault observations carry no outputs.
- Structural validation is deliberately not admission, semantic approval,
  commit, visibility, or Experience authority. ObjectManifest/table lifecycle
  and rings remain T-0031; Linux still transports only PING/NOP.
- `scripts/ci-local.sh` exited 0 with all 55 tests and the unchanged Sonatine
  release/debug/DWARF/QEMU checks. The T-0030 strict-C11 host test passed under
  Apple clang 21.0.0 with `-pedantic-errors -Wall -Wextra -Werror`.
- The default public Debian base metadata lookup timed out in this session.
  The reproducible Dockerfile was therefore verified with the already-audited
  local Debian-derived base override:

      docker build --build-arg BASE_IMAGE=raveil-sonatine:gate0-clean-20260808 -f linux/Dockerfile -t raveil-linux-driver .

  Debian arm64 GCC 12.2.0 compiled the Linux daemon/client and the shared job
  validator with `-Werror`. Image identity was
  `sha256:2619082d2573496975b5423440fff84d02830aa83fb2e7cff8bfb8687f101453`.
  A UID/GID 65534 private-tmpfs smoke again exited 0 with socket mode 600,
  `raveil linux driver ping: OK`, and endpoint cleanup. This does not claim
  Linux transport of JobDescriptor; the driver remains PING/NOP-only.
