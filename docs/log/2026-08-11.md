# 2026-08-11

## T-0084 Linux driver-development harness

- PM review retained ADR-0003: Linux does not replace the permanent
  RISC-V/Sonatine control and authority path. ADR-0019 makes Linux a
  non-authoritative development and transport-validation host.
- Added a fixed 32-byte request/completion v1 ABI with PING/NOP only and a
  pure-C one-inflight core. Invalid magic, version, size, flags, and opcode
  fail closed; busy and empty states remain distinct.
- Added Linux-only same-UID `SOCK_SEQPACKET` daemon/client sources. The daemon
  requires an absolute `XDG_RUNTIME_DIR`, creates a private endpoint under
  umask 0077, rejects partial messages with `MSG_TRUNC`, and exposes no network,
  root, kernel module, pointer, file-descriptor passing, DMA, MMIO, or
  Experience boundary.
- `scripts/ci-local.sh` exited 0 with all 54 tests, release/debug Sonatine
  builds, DWARF checks, and QEMU smoke on macOS 26.5.1 arm64 using Python
  3.14.6, Apple clang 21.0.0, `riscv64-elf-gcc` 16.1.0, binutils
  2.47.20260726, and QEMU 11.0.3.
- `docker build -f linux/Dockerfile -t raveil-linux-driver linux` exited 0 on
  Docker Linux arm64. Debian bookworm GCC 12.2.0 compiled both Linux-only
  binaries warning-free. The image identity was
  `sha256:1f19fe3b2be57fbb159ded26887afd2986341b05d4d25d91280bc861b3d46231`.
- The non-root smoke used UID/GID 65534 and a mode-0700 `/runtime` tmpfs. The
  Docker frontend left the invocation in Created state in this session, so the
  same configured container was started explicitly with `docker start -a`.
  It exited 0, observed socket mode 600, printed
  `raveil linux driver ping: OK`, and verified endpoint cleanup.
- Host-core and Linux-container results are correctness evidence only.
  Kernel-device, QEMU-device, FPGA, silicon, and performance evidence remain
  separate and are not claimed.
