## T-0022 PolicyOutcome integrity boundary

- Accepted ADR-0012 and split oracle-free pre-measurement `PolicySelection`
  evidence from run-bound `PolicyOutcome` summaries.
- Gate analysis now requires exactly one cold, bounded, and full-history pair
  for every manifest workload and rejects missing, duplicate, unknown,
  wrong-run, wrong-manifest, wrong-budget, late, or unregistered-candidate
  evidence.
- Baseline, selected, and offline-oracle latency/energy values are recomputed
  from raw `MeasurementRecord` medians. Tampered summary metrics fail closed.
- This is contract and analysis implementation evidence only. No production
  policy matrix, full fixed-C result, performance improvement, or Gate
  conclusion was produced; T-0022 remains open.
