# Research references

This directory contains draft, machine-readable metadata for external papers,
manuals, talks, and whitepapers used by Raveil records. It does not contain
third-party source files and does not make literature authoritative for Raveil
implementation, measurement, decisions, or Gate status.

The current draft is [`catalog.json`](catalog.json), governed only as a proposal
by [RFC-0003](../rfcs/RFC-0003-reference-and-research-synthesis.md). Missing
metadata is explicit. Raveil-authored abstracts apply only to research papers.
Manuals, vendor pages, presentations, and talks receive prior-art notes instead;
those notes are not abstracts or implementation recommendations. Both forms are
derived from the cited repository memo and must be checked against a fixed
primary-source version before promotion to a locator-backed claim.

Reference availability or copyright permission does not establish patent
clearance. An `unreviewed` patent status is research context only, not a
freedom-to-operate conclusion.

Do not add PDFs or copied abstracts here. Lawfully retained source bytes belong
only in the ignored `artifacts/reference-library/` boundary proposed by
RFC-0003.
